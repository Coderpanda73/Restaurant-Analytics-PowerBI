RESTAURANT ANALYTICS DASHBOARD USING POWER BI

PROJECT OVERVIEW

This project is an interactive Restaurant Analytics Dashboard developed using Microsoft Power BI. It analyzes restaurant business data to understand revenue performance, customer behavior, restaurant ratings, order trends, and delivery operations.

The objective of this project is to transform raw data into meaningful visualizations that help understand business performance and support data driven decision making.

PROJECT OBJECTIVES

Analyze revenue and order trends over time.

Evaluate restaurant performance based on revenue and ratings.

Understand customer behavior and repeat customer activity.

Analyze order status, cancellations, and delivery performance.

Explore relationships between restaurant ratings and business performance.

TOOLS AND TECHNOLOGIES

Microsoft Power BI Desktop for report development and data visualization.

Power Query for data preparation and transformation, where applicable.

DAX for creating measures and calculating key performance indicators, where applicable.
